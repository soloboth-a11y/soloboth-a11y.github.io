# トップの アニメーション（スプライトシート）

このフォルダに スプライトシートの画像を入れると、トップ画面の「シールあつめ」の となりに
アニメーションとして出てきます。トップを ひらくたびに、どれか1つが ランダムな場所に出ます。

## ファイル名の つけかた

ファイル名の さいごに、コマの ならびかたを書きます。

| ファイル名の例 | いみ |
| --- | --- |
| `ねこ_8x1.png` | よこ8コマ × たて1だん |
| `いぬ_4x2.png` | よこ4コマ × たて2だん（左上から右へ、つぎの だんへ） |
| `とり_4x2_7f.png` | 4×2 のうち、はじめの 7コマだけ つかう（さいごが あまっているとき） |
| `うさぎ_6x1_12fps.png` | 1びょうに 12コマの はやさ（かかないときは 8） |
| `くま.png` | ならびを かかないとき：よこ1れつに 正方形のコマが ならんでいるとみなす |

- コマは ぜんぶ 同じ大きさに してください
- せなかが すけている（透明な）PNG がおすすめです
- 1コマが 64ピクセル以下の 小さい ドット絵は、ぼやけないように くっきり表示します

`見本-ほし_8x1_10fps.png` は 見本です。いらなくなったら けしてください。

画像を入れてプッシュすると、GitHub Actions が 一覧（`sprites.json`）を作って サイトを公開し直します。
