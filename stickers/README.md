# シールの画像

このフォルダに画像を入れると、それがアプリのシールになります。

- 使える形式: `.png` `.jpg` `.jpeg` `.gif` `.webp` `.avif` `.svg`
- ファイル名は自由です（日本語でも大丈夫）
- 正方形に近い画像がきれいに見えます。透明な背景の PNG もおすすめです
- 1枚あたり 500KB くらいまでにしておくと、表示が速くなります

画像を入れてプッシュすると、GitHub Actions が画像の一覧（`stickers.json`）を作ってサイトを公開し直します。
このフォルダに画像が1枚もないときは、絵文字のシールが使われます。

すでにもらった絵文字のシールは、画像を入れたあともシールちょうに残ります。

## レア度（出にくさ）

ファイル名の先頭を「数字2桁_」にすると、レア度になります。数字が大きいほど出にくくなります。

| ファイル名の例 | レア度 | 出やすさ |
| --- | --- | --- |
| `ねこ.png`（数字なし） | 1 | ふつう |
| `01_いぬ.png` | 1 | ふつう |
| `03_うさぎ.png` | 3 | ふつうの 1/3 |
| `10_ドラゴン.png` | 10 | ふつうの 1/10 |

まだもらっていないシールから先に選ばれるので、レアなシールもいつかは必ずもらえます。
